# MERN Notes App 🚀

A full-stack Notes Application built using the MERN Stack.

## Features ✨

- User Authentication
- Add Notes
- Edit Notes
- Delete Notes
- Search Notes
- Pin Notes
- Dark Mode
- Responsive UI

## Tech Stack 🛠

Frontend:
- React.js
- Axios
- Tailwind CSS

Backend:
- Node.js
- Express.js
- MongoDB
- JWT Authentication

## Installation ⚡

### Clone Repository

```bash
git clone https://github.com/Aditya-gupta149/mern-notes-app.git
```

### Frontend Setup

```bash
cd frontend
npm install
npm start
```

### Backend Setup

```bash
cd backend
npm install
npm run dev
```
